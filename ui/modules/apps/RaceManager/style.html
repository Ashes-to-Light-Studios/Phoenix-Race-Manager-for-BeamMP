Tower columns

What ?view=tower shows right of each driver's name, in order. Click a column to add it, or type the names with commas between them. Place, number, team logo and name are always there. With more than the gap, each column's name shows above it. A link's &cols= wins over this, for a second tower.

Banner

What ?view=banner shows, left to right. Click an item to add it, or type the names with commas between them. New page starts another: the banner turns through its pages, and steps through the running order a few drivers at a time. The logo, the flag and the sponsor stay put on every page. A link's &show= wins over this, for a second banner that shows something else.

Files

Logos, sponsor art, fonts and a stylesheet, kept in the game's user folder (settings/raceManager/overlay/). PNG, JPG, GIF, WebP, SVG; WOFF2, WOFF, TTF, OTF; CSS.

Drop files here, or

Advanced

Custom stylesheet (a CSS file from Files, loaded after the overlay's own)

The overlay's parts have plain class names (.row, .name, .carno, .badge…), and rows carry data-team, data-class and data-pos, so a stylesheet can single out one team or the leader. Colors set here win over a stylesheet's unless it says !important.
